## Fixes applied after first boot

**Stale jail directory (EEXIST):** `setup_jail` now removes any leftover jail
from a previous run before recreating it. Ctrl-C during a run left
`/srv/jailer/firecracker/vm-test-001/root/` behind; the next launch failed
with EEXIST on mknod.

**Kernel file zeroed during pool reimport:** `$(POOL_SENTINEL)` listed
`$(KERNEL_LINK)` as a Make prerequisite, causing `make pool` to re-evaluate
the kernel symlink target during pool reimport. Removed the kernel (and jailer)
from pool dependencies — pool only needs the base image.

**Root password:** base rootfs had an unknown password hash. Replaced it by
loop-mounting `browser-rootfs.ext4`, running `sed` against `/etc/shadow`, then
doing a full pool purge and reimport. Password is now `microvisor`.

**Kernel file restoration:** `resources/vmlinux-6.1.bin` was zeroed by the
above incident. Re-downloaded from Firecracker's S3 quickstart bucket.
