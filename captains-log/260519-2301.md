## Achievements

### ADR-012 Phase A (commit `1a9caf1`)

1. **`prctl(PR_SET_PDEATHSIG, SIGKILL)`** — set via `CommandExt::pre_exec` immediately after fork, before exec. The closure runs in the child process in a post-fork/pre-exec context where only async-signal-safe calls are legal; `prctl(2)` qualifies. Prevents orphan Firecracker processes accumulating if the orchestrator crashes.

2. **`ProvisioningContext`** — tracks non-RAII resources (DM snapshot name, IPAM slot, cgroup, process) as `Option<T>` fields. `launch_vm` calls `ctx.cleanup()` on any error path; cleanup releases in reverse allocation order. Each field is `take()`-d exactly once, making the whole thing idempotent. Individual cleanup failures are warned but don't abort the remaining steps.

3. **`EbpfProgram` lifetime bug fix** — the program was previously held in a local `_ebpf` variable in `launch_vm`, causing the tc hooks to detach when the function returned. `EbpfProgram` is now a field on `Vm`, keeping the hooks live for the VM's full lifetime.

## Technical Decisions

- `TapDevice` and `EbpfProgram` are left as locals in `provision_vm` (RAII cleanup on Drop). Only the non-RAII resources go into `ProvisioningContext`.
- Cleanup order: kill process → delete cgroup → release IPAM → remove snapshot. Process must vacate the cgroup before the cgroup directory can be removed.
