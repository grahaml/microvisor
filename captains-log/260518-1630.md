# Captain's Log: 260518-1630

## Achievements
- **Dogfooding Strategy:** Formalized the decision to run the observability stack inside a "System MicroVM" managed by the Microvisor itself (ADR 008).
- **Static IPAM:** Updated the `IpAm` module to support static IP reservations, reserving `10.0.0.2` for the telemetry system VM.
- **OpenTelemetry Integration:** Integrated `tracing-opentelemetry` and the OTLP exporter into the Rust control plane.
- **Unified Tracing:** Configured the control plane to simultaneously emit JSON logs to stdout and OTLP traces to the telemetry VM.
- **Telemetry RootFS Script:** Created `scripts/telemetry/build-rootfs.sh` to automate the creation of an Alpine-based image containing the OTel Collector and Jaeger.

## Technical Decisions
- **OTel over Vector:** Chose the OpenTelemetry Collector as the initial aggregator due to its mature OTLP trace ingestion, despite its larger footprint compared to Vector.
- **In-Memory Storage:** Enforced in-memory storage for Jaeger within the microVM to prevent host disk exhaustion.
- **OTLP over gRPC:** Standardized on OTLP/gRPC for high-performance telemetry export from the control plane.
